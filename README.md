# Date and Time Utility

This project is a Python program that performs common date and time calculations using the built-in `datetime` module. It validates user input and provides useful date-related operations.

Features

Calculate age from date of birth.

Find the number of days between two dates.

Calculate working days between two dates.

Display the current date, time, and day.

Run the program using:

`python dateutility.py`

Requirements

Python
